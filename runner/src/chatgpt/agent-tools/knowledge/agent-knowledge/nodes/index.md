# Available Node Types

These are the currently supported Automatio node types:

- `trigger`
- `goto`
- `click`
- `fill`
- `select`
- `check`
- `uncheck`
- `press`
- `wait`
- `wait_for_element`
- `screenshot`
- `extract_text`
- `assert_text`
- `assert_value`
- `condition`
- `loop`
- `parallel`
- `call_api`
- `call_chatgpt`
- `telegram`
- `end`

When a node needs to be created, retrieve the corresponding `nodes/<type>.md` knowledge file if its exact configuration is not already known.

Do not invent node types.
